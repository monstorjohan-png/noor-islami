# نور — NOOR

رفيق يومي للقرآن والحديث والأذكار، يعمل بالكامل دون إنترنت، ويُثبَّت من المتصفح على الهاتف.

---

## ما هو

تطبيق ويب تقدّمي (PWA) عربي أولاً مع مفتاح إنجليزي. لا يحتاج خادماً: كل شيء في ملفات ثابتة.

| القسم | المحتوى |
|---|---|
| المصحف | ٦٢٣٦ آية بالرسم العثماني، تفسير و٢ ترجمتين، ٣٠ جزءاً و٦٠٤ صفحات |
| الحديث | ٩ كتب بأسانيدها ودرجاتها، ٣٦٠٦٤ حديثاً |
| الأذكار | ٢٧ ذكراً مؤكَّداً، مجموع ٧٧ رتبة |
| الصلاة | ٦ مواقيت، ٤ مذاهب، ١٦ طريقة حساب، قبلة، تقويم هجري |
| الأسماء | ١٠٠ اسم من أسماء الله الحسنى |
| التلاوة | ٦ قرّاء، مع حفظ السورة للعمل دون إنترنت |

## المصادر

كل نص ديني في التطبيق من مصدرين مرخَّصين فقط:

- المصحف — `fawazahmed0/quran-api`
- الحديث — `fawazahmed0/hadith-api`

لا نص ديني مكتوب من الذاكرة. كل ذكر وكل اسم اسم الله يقابله موضع آية أو رقم حديث في المصدر؛ فإن لم يوجد أُسقط وسُجّل في `public/data/gaps.json` بدل ملئه من عندنا. تكشف الفجوات في الطبعة المفتوحة: البخاري ٩ أحاديث ناقصة، مسلم ٢٠٣.

## بوابة الجودة

كل أمر يجب أن يمرّ قبل أي ادّعاء بأن شيئاً يعمل:

```powershell
npx tsc -p tsconfig.json --noEmit   # الأنواع
node scripts/check-encoding.mjs     # تلف النص العربي
node scripts/verify-content.mjs     # نزاهة المحتوى الديني

```

البوابة نفسها تعمل تلقائياً في `.github/workflows/quality.yml` عند كل push.

## قرارات تهم من يستعمل التطبيق

- **تشريح المصحف**: فتح أي سورة يقرأ ٥١٣ كيلوبايت بدل ٦٫٣ ميغا — أقل ٩٢٪. البحث يقرأ فهرساً أخف بلا تفسير ولا ترجمة.
- **الخط مضمَّن**: `Amiri Quran` في `public/fonts/` برخصته، ولا يعتمد على خط الجهاز ولا على شبكة خارجية. الرسم العثماني يظهر دائماً.
- **التلاوة دون إنترنت**: زر «حفظ التلاوة» في صفحة السورة ينزّل ملف السورة إلى ذاكرة عامل الخدمة فيعمل بعدها بلا إنترنت.
- **التنبيه يعمل أثناء تشغيل التطبيق**: جدولة في الذاكرة، وعامل خدمة، ومزامنة دورية في الخلفية (أندرويد). **ملاحظة**: عند إغلاق التبويب تموت مؤقتات `setTimeout` — التنبيه والإطبيق مغلق تماماً يحتاج Web Push + خادم مفاتيح VAPID، وهو غير متاح على استضافة ثابتة مجانية. الرابط المباشر `Notification API` يعمل فقط والصفحة حية.
- **تخزين دائم**: التطبيق يطلب `navigator.storage.persist()` بعد التنزيل ليحمي ٦٨ ميغا من الحذف التلقائي.

## الحماية

التفاصيل الكاملة في `SECURITY.md`. ملخّص البنية:

| الطبقة | التفصيل |
|---|---|
| سياسة أمان المحتوى | `public/_headers` — سكربت من نفس المصدر فقط، بلا `eval`، بلا إطارات، بلا أجسام مضمّنة |
| حارس المسارات | `src/lib/safe.ts` — نقطة اختناق واحدة تحرس كل مسار ملف قبل أن يصير طلباً للشبكة |
| تنقية التخزين | كل حقل يُعاد بناؤه عند الاستعادة، ومفاتيح `__proto__` تُحذف |
| حاجز الأخطاء | `src/components/ErrorBoundary.tsx` — لا شاشة بيضاء أبداً، مع زرّ لمسح بيانات الجهاز |
| روابط التلاوة | كل قارئ مُختبَر بطلب حقيقي إلى الشبكة، ومعدّل لكل قارئ على حدة — لا رابط ميت |
| ذاكرة عامل الخدمة | مثبّتة على مضيف التلاوة وحده، بسقف عدد وسقف عمر |
| التحديث | لا يستبدل العامل نفسه تلقائياً — المستخدم يُخبر بوجود نسخة جديدة ويقرّر |

## القرّاء

أحد عشر قارئاً، كل واحد منهم **مُختبَر بطلب حقيقي** إلى شبكة التلاوة قبل أن يدخل القائمة:

| القارئ | تلاوة الآية | ملف السورة كاملة |
|---|---|---|
| مشاري راشد العفاسي | نعم | نعم |
| عبد الباسط عبد الصمد — مرتل | نعم | نعم |
| عبد الباسط عبد الصمد — مجوّد | نعم | — |
| محمود خليل الحصري | نعم | — |
| محمود خليل الحصري — مجوّد | نعم | — |
| محمد صديق المنشاوي | نعم | — |
| سعود الشريم | نعم | — |
| علي الحذيفي | نعم | — |
| ماهر المعيقلي | نعم | — |
| أبو بكر الشاطري | نعم | — |
| محمد أيوب | نعم | — |
| عبد الله بصفر | نعم | — |

قارئان فقط لهما ملف السورة الكاملة على الشبكة، وعليهما وحدهما يظهر زرّ **حفظ التلاوة** للعمل دون إنترنت. أمّا الباقون فيتلون آية آية، ويقول التطبيق ذلك صراحةً بدل أن يعرض رابطاً ميتاً.

الفارق بين القرّاء ليس في الاسم: **لكل قارئ معدّل خاص** (٦٤ أو ١٢٨ كيلوبايت)، يختلف حتى بين ملف الآية وملف السورة لنفس القارئ. افتراض معدّل واحد للجميع يجعل روابط أربعة قرّاء ميتة — وهذا ما كان يحدث قبل هذا الإصلاح.

لإعادة الفحص أو إضافة قارئ:

```powershell
npm run probe:reciters
```

يكتب ما وجده في `.cache/reciters-probe.json`، ومع `--write` يحدّث القائمة في `src/lib/audio.ts` تلقائياً. لا تُضِف قارئاً إلى القائمة قبل أن يثبته هذا الفحص.

## الحسابات

الافتراضي **وضع الضيف**: التطبيق كامل بلا حساب وبلا مفتاح وبلا خادم.

الحسابات (دخول بجوجل · إنشاء حساب · دخول ببريد) تُفعَّل بمفاتيح `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في `.env.local`. انظر `.env.example`. بدونها لا يُحمَّل كود المصادقة ولا يُصدر التطبيق طلباً واحداً.

## النشر

**موقع التطبيق الحي**: `https://monstorjohan-png.github.io/noor-islami/` — يُنشر تلقائياً على GitHub Pages عند كل دفعة إلى `main`. النطاق الفرعي مجاني ودائم ما دام المستودع موجوداً، وعرض النطاق الناعم ١٠٠ جيجابايت/شهر.

GitHub Pages يستدعي `quality.yml` (الأنواع + الترميز + المحتوى + الاختبارات + البناء) عبر `workflow_call` — بوابة واحدة لا تتكرر.

```powershell
gh auth login
git push -u origin main
```

Cloudflare Pages خيار بديل (عرض نطاق غير محدود، ٥٠٠ بناء/شهر) — يحتاج أسرار `CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID` في مستودع GitHub، وغيابها يُخطي النشر بلا فشل.

`dist/` ملفات ثابتة — أي استضافة ثابتة تكفي. المطلوب HTTPS لأن عامل الخدمة والإشعارات لا تعملان بدونه.

```powershell
npm run build
# ثم ارفع محتويات dist/ إلى أي استضافة ثابتة
```

## اختياري: حزمة أندرويد

المشروع PWA في أصله. للتحويل إلى APK عبر Capacitor:

```powershell
npm i -D @capacitor/cli @capacitor/core @capacitor/android
npx cap init noor app.noor --web-dir=dist
npx cap add android
npx cap sync
npx cap open android
```
