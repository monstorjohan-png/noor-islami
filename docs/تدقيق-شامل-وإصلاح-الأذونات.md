# الدفعة ما قبل الأخيرة (2026-11-17 مساءً) — إصلاح الأذونات والتدقيق الشامل

## الأخطاء المبلغة وإصلاحاتها

| الخطأ المبلغ | السبب الحقيقي | الإصلاح |
|---|---|---|
| «لا يعمل التسجيل» / «تحديد الموقع لا يعمل ولا يطلب التطبيق أي أذونات» | APK كانت بلا RECORD_AUDIO/LOCATION في المانيفست — Capacitor يطلبها runtime ويمنعها النظام إن لم تُصرَّح | `android/.../AndroidManifest.xml`: RECORD_AUDIO + MODIFY_AUDIO_SETTINGS + ACCESS_COARSE/FINE_LOCATION + POST_NOTIFICATIONS + VIBRATE — مُتحقّق من داخل APK نفسه (aapt) |
| «أي سورة غير الفاتحة لا تعمل ويظهر خطأ» | بناء بفضل `./` كـ base أُطلقت أصول المصحف من مسار خاطئ على التوجيهات العميقة في الويب فيو | ✅ مُثبت على `/` + اختبار APK يعيد الحزمة أصول all 114 سورة بداخلها (٥٢٥ كيلوبايت لكل واحدة) |
| «التنزيل لا يعمل جيداً ولا يحفظ» | تأكّد عملياً في المتصفح: التنزيل يُتمم ويغيّر الزر إلى «حذف» (يحفظ في IDB) — اتصل بالأخطاء من البناء القديم | ✅ يعمل: تنزيل واحد أُثبت عملياً وتغيّر زرّه إلى «حذف» |
| أذونات التنبيهات لا تظهر | إضافة POST_NOTIFICATIONS يجعل Android 13+ يعرض طلب الإذن | ✅ مُضاف + VIBRATE للتنبيهات |

## التدقيق الشامل (٢٢ مساراً + تفاعلات) — كلها سليمة

المسارات المُتحقق منها بالكامل دون أخطاء console: القراءة، الحفظ، التسميع (التفاعلي + التلاوة + اكتب وتلا)، الأذكار، الحديث + القارئ، الصلاة، القبلة، التسبيح (عدّاد يعمل)، الأسماء، التقويم، البحث، العلامات، التنزيل (زر التنزيل ينفّذ ويحفط)، الإعدادات، المزيد، الفقه، التاريخ، التراجم، متشابه، التجويد، لوحة رحلتي، المصادر — كل المسارات سليمة تماماً (فقط ملاحظة إطارات الوصلة الوصفية غير الضارة).

التحقق من APK نفسه:
- الأذونات الموجودة داخل الحزمة (`aapt dump permissions`) ✓
- ملفات المصحف كلها داخل APK (114/114 بتحقق فعلي) ✓
- المسارات العميقة تعمل (base=`/` + عامل الخدمة) ✓

## تنبيه للتجربة

- على الهاتف: احذف النسخة القديمة، ثبّت `NOOR.apk` من سطح المكتب، ثم عند أول استخدام للتسجيل أو تحديد الموقع ستظهر نافذة الإذن الأصلية.
- إن بقي من النسخة القديمة شيء غريب: الإعدادات ← التطبيقات ← نور ← تخزين ← مسح (بيانات التطبيق القديمة قد تحوي نسخة قديمة مخزنة في IndexedDB).
