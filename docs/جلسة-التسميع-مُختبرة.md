# جلسة التسميع + وضع «اكتب وتلا» — مُختبرة كاملة في المتصفح (2026-11-17)

## ما تم التحقق منه عملياً

| الخطوة | النتيجة |
|---|---|
| اختيار السورة (شبكة ١١٤ سورة) | ✓ الإخلاص تعمل |
| قائمة الأوضاع الخمسة (اكشف/الكلمة الناقصة/رتّب/التسجيل/اكتب وتلا) | ✓ تُعرض كلها بالترتيب ويُختَار منها |
| جلسة «اكشف بعد المحاولة» ١/٤ حتى ٤/٤ | ✓ الآيات تُكشف وتُقيَّم وتتقدم |
| شاشة الإتمام «اكتملت الجلسة — ما شاء الله أكملت التسميع» | ✓ تظهر بالأعداد والتفصيلات |
| وضع «اكتب وتلا» — الآية مخفيّة والنص يُكتب كلمةً كلمة | ✓ مُتحقّق بصرياً: «قل هو الله احد» → ٤ كلمات خضراء، وعدّاد ٤/٤ و١٠٠٪ مطابقة، وزر «إنهاء ومراجعة» |
| مشاركة الجلسة (انتهاء → سورة أخرى) | ✓ الزر يعمل |

## نتيجة التدقيق الكامل على المتصفح (2٢ مساراً)

كل المسارات سليمة بلا أخطاء console: القراءة، الحفظ، التسميع بكل أوضاعه، الأذكار، الحديث + القارئ، الصلاة، القبلة، التسبيح، الأسماء، التقويم، البحث، العلامات، التنزيل، الإعدادات، المزيد، الفقه، التاريخ، التراجم، متشابه، التجويد، لوحة رحلتي، المصادر.
